A calendar reminder cannot catch any of this

The date is in the past
You cannot set a reminder for something that already happened

The CPF ceiling moved on 1 January 2026. A calendar entry would have fired months ago, assuming somebody knew to write it. Ante reads today’s payroll against today’s law, so a rule that started biting last year still shows up first.

There is no date
Some obligations are a line you cross, not a day that arrives

GST registration triggers on turnover, not on a deadline. It has no date to put in a diary. Ante watches the threshold against your own figures and tells you how close you are.

The number moves
The figure you wrote down last quarter is not the figure today

A threshold in the vault is a claim about a page. The curator re-reads that page every morning and rewrites the rule only when it can quote the new figure off it.

Three steps, then it runs itself

01
Drop in a payroll CSV

Name, salary, pass type, date of birth, pass expiry. Column names are matched against an alias table, never guessed by a model. Anything it cannot identify comes back as a question against the row, because an unrecognised pass type moves money.

02
The curator reads the sources

Every morning it re-fetches the government pages behind each rule, compares them to what the vault says, and rewrites a rule only when it can quote the new figure verbatim from the page it says it read. When it cannot, it escalates to a person instead of guessing.

03
The board ranks what bites

Findings are ordered by when they hit you, not by category. Each one carries who it affects from your own roster, what it costs in a human-written note, and the next step to take. Ask Ante is there for the drill-down, but the answer is already on the page.
